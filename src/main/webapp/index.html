Relay: -

    

    

      
      

    
Relay: Paula resends the data it hears (Chinampa, Daffodils, their vital signs and link health) so Annabelle gets a second chance. Stand it between the device and the house, then compare Annabelle's "Delivered here" with it on and off. Noise: lower is better; a rise of 10 dB or more means something nearby is interfering - walk towards higher readings to find it.

  

  

  
  

    
    
  

  

  

    
    
  

  
  

    
    
  

  

  

  

  
"WiFi on" keeps a Daffodil awake with WiFi for 15 minutes; then connect the phone to its hotspot. A sleeping one answers when it next wakes.

  
Paula's secret

  
Paula's commands carry a code made from the customer's secret. If Paula's secret is different, every command is rejected (and Paula's LEDs 2-3 stay red). Plug one of the customer's Daffodils into the Pi (jumper on USB), then check or copy. The secret is never shown.

Test Flow Sensor

        
      

      

        
Make sure the jumper is on the digital header. Turn the water on before starting. Then watch Paula's LEDs: 15s red (get ready), then 10s green - the pulses are counted only during the green phase and shown here when it ends. If the sensor is inline, the pulse count is the test; if you catch the water during the green phase, enter its volume for a new qfactor.

        

          
          
        

        
        

          
          
        

        

      

      

        
      

    

  







  

    

      

        
Test Ultrasonic Sensor

        
      

      

        
Make sure the jumper is on the digital header. DYP-A02-V2.0, UART automatic output mode - connect its TX lead to pin 18.

        
        

      

      

        
      

    

  







  

    

      

        
Test Tank Pressure

        
      

      

        
Make sure the jumper is on the analog header (opposite of the flow/ultrasonic tests). 0.5V-4.5V/0-5psi transducer - a near-0V reading usually means disconnected/faulty, not truly 0psi.

        

          
          
        

        
        

      

      

        
      

    

  







  

    

      

        
Test Soil Sensor

        
      

      

        
RS485 7-in-1 soil probe (Modbus-RTU, 9600 8N1) on the RS485 terminal: GND, VDD, A, B. Needs Paula build 2 - build 1 has no RS485. Sensor power is 3.3V-24V, so check the VDD terminal voltage first. Push the probe fully into soil; pH needs over 5 minutes after first power-up to settle.

        

          Sensor address
          
        

        
Factory default is 2. Use 0 (broadcast) to discover an unknown address, with only this one sensor connected.
